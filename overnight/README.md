## Итог

- оптимум интерьерный (не на границе диапазона)
- за пиком уступка хеджа растёт 0.97% → 1.75%: ограничитель — глубина тонкой биржи
- доля приходящего объёма в пике по order_size: 1.7%…2.7% — инвариант, оптимум экономический
- в базе при T=12000: mean +71.6, банкротств 0/20
